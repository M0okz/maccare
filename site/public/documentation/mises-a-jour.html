Guide · Mises à jour

Comprendre les sources et la couverture.

MacCare rassemble les résultats disponibles et vous laisse choisir comment mettre à jour.

Dans la version publiée

Dans MacCare 0.2.17, Applications → Mises à jour combine le catalogue public Homebrew, les apps gérées par Homebrew, l’App Store et les sources officielles dédiées. L’outil App Store est embarqué : il ne demande pas d’installer Homebrew ou mas séparément.

Les résultats présentent les versions et, lorsque la source les fournit, les nouveautés, la date et la taille du téléchargement. Les actions ouvrent l’app, l’App Store ou proposent une commande à copier. MacCare n’installe pas ces mises à jour automatiquement.

Le catalogue hybride

Disponible depuis MacCare 0.2.17

Le catalogue hybride est inclus dans le téléchargement public de MacCare 0.2.17.

Le catalogue hybride consulte le catalogue public Homebrew, même si Homebrew n’est pas installé et si l’app a été téléchargée directement chez son éditeur. Elle rapproche localement le nom du paquet et son identifiant, puis compare la version installée à la version référencée.

Des sources officielles complètent le catalogue : NetNewsWire garde son flux Sparkle et ArtCraft Launcher dispose d’une fiche dédiée vers son dépôt GitHub officiel. Pour ces nouveaux résultats, un bouton ouvre le site de l’éditeur ou la page de la release.

7 822 fiches ne signifient pas 7 822 apps reconnues

Le catalogue consulté le 9 novembre 2026 contenait 7 822 fiches. Certaines décrivent des variantes, polices ou paquets ; d’autres ne fournissent pas les informations nécessaires à une comparaison fiable.

MacCare retient les éditions qu’il peut identifier sans ambiguïté. Il écarte notamment les préversions, les versions non comparables et les plateformes incompatibles. Une app absente des résultats n’est donc pas nécessairement à jour.

Les mises à jour visant le même logiciel sont regroupées quand la correspondance est établie. Une source inaccessible laisse la vérification explicitement incomplète. Les métadonnées communautaires peuvent aussi prendre du retard sur celles de l’éditeur.

Exemples vérifiés en développement

La vérification du catalogue a remonté des mises à jour réelles pour Cursor, Figma, Google Chrome, Firefox, CleanShot X, AFFiNE et d’autres apps sur le Mac de test. Ces exemples illustrent la détection ; ils ne garantissent pas toutes les éditions de ces logiciels.

ArtCraft a été vérifié avec une ancienne installation simulée et la vraie API GitHub. Il n’était pas installé sur le Mac de test.

Un rapprochement effectué sur le Mac

Le téléchargement du catalogue public n’envoie pas votre inventaire d’applications. Les correspondances se font localement. Les sources officielles dédiées sont interrogées pour les apps correspondantes installées.

Le catalogue ne sert pas à supprimer des fichiers. Voir son rôle par rapport à la désinstallation.

Sources : API publique Homebrew, versions officielles d’ArtCraft Launcher.
