Guide · Premiers pas

Installer MacCare et lancer une première analyse.

Prenez vos repères avant de choisir ce que vous souhaitez modifier.

Installer MacCare

  1. Téléchargez le DMG depuis le site MacCare.
  2. Ouvrez-le, glissez MacCare dans Applications, puis lancez l’app depuis ce dossier.
  3. Choisissez une rubrique et lancez son analyse. Examinez les résultats avant toute action.

La distribution actuelle cible les Mac Apple Silicon avec macOS 13 ou ultérieur. Elle est signée avec un certificat Developer ID et notariée par Apple.

Accorder les accès utiles

L’accès complet au disque permet de lire certains dossiers que macOS protège. Sans lui, les analyses concernées peuvent rester incomplètes. MacCare vous oriente vers les Réglages Système pour l’accorder.

L’assistant système est facultatif. Il sert aux opérations qui demandent des droits élevés, notamment certains contrôles de batterie et outils système. Son activation nécessite votre approbation dans macOS.

Analyser, examiner, choisir

Une analyse recense les éléments et mesure leur taille. Elle ne les supprime pas. Les gestionnaires présentent ensuite les détails, les chemins et les actions disponibles.

Vérifiez les cases cochées : la sélection initiale dépend de l’outil. Dans le désinstalleur, le paquet et les données associées détectées sont sélectionnés ; vous pouvez décocher chaque élément.

Garder MacCare à jour

Le menu MacCare → Rechercher les mises à jour… concerne MacCare lui-même. Les recherches automatiques sont désactivables dans les réglages. L’installation demande votre action.

Pour les autres logiciels du Mac, utilisez Applications → Mises à jour.
