# MacCare 0.2.48

- La désinstallation d’une application de l’App Store retire aussi ses conteneurs. Le mot de passe administrateur ne sert plus qu’au paquet et aux fichiers d’un autre compte ; vos données sont retirées avec les droits de MacCare.
- Lorsque l’Assistant système est activé, la désinstallation se confirme avec Touch ID ou le mot de passe de votre session. Mettez à jour l’assistant depuis **Batterie** pour en profiter.
- Si macOS protège un conteneur, MacCare l’annonce avant la désinstallation et indique d’accorder l’Accès complet au disque, au lieu d’un simple « Operation not permitted ».
- Une fenêtre confirme désormais que l’application a été désinstallée, avec les éléments retirés et l’espace libéré. Le gestionnaire retrouve aussi les caches WebKit et les préférences propres au Mac de chaque application.
