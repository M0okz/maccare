# MacCare 0.2.45

- Le gestionnaire d’applications vérifie la version installée pendant une mise à jour App Store. Si l’App Store tarde à répondre, MacCare reconnaît la mise à jour dès qu’elle apparaît sur le disque.
- Si l’installation reste à confirmer après deux minutes, le gestionnaire vous rend la main. Vous pouvez aussi choisir « Arrêter le suivi », ouvrir la fiche App Store ou vérifier à nouveau l’installation.
