# MacCare 0.2.47

- Le désinstalleur retrouve les fichiers de l’application et de ses assistants de connexion, y compris leurs conteneurs, scripts et caches temporaires. Vous pouvez aussi sélectionner les composants tiers associés installés pour tous les utilisateurs du Mac.
- Quand les droits de votre session sont insuffisants, MacCare demande une autorisation administrateur pour la sélection. Le bilan **Détails** affiche le résultat de chaque fichier et la raison des éléments conservés ou en échec.
- Dans le Smart Scan, la vue **Par application** regroupe les éléments détectés et leur taille. Le nettoyage reconnaît aussi le cache de démarrage de Visual Studio Code et tient compte des applications ouvertes.
