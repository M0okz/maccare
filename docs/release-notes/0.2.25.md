# MacCare 0.2.25

- Corrige l’erreur « Failed to get sudo uid » qui bloquait les mises à jour App Store, notamment Bitwarden, après l’autorisation administrateur.
- Replace le bouton jaune de mise à jour à droite de la fenêtre sur les versions récentes de macOS.
- Ajoute une bannière macOS lorsqu’une nouvelle version de MacCare est détectée automatiquement. Un clic ouvre les nouveautés et les options d’installation, même si la fenêtre principale était fermée.

Les notifications sont réglables dans **Réglages → Général → Mises à jour de MacCare** et nécessitent l’autorisation de macOS. Une seule alerte est envoyée par version. MacCare doit rester actif, y compris dans la barre des menus ; aucune alerte n’est envoyée quand l’app est complètement quittée.
