# MacCare 0.2.1

- Permet de retenter explicitement l’enregistrement de l’assistant depuis Batterie,
  même lorsque macOS le signale encore en attente d’approbation.
- Ouvre les Réglages Système si l’approbation administrateur reste nécessaire.
- Conserve les erreurs de signature et les autres échecs d’enregistrement visibles.
- Interroge un assistant déjà activé sans le réenregistrer ni démarrer la protection.
- Identifie la version, le build et le canal dans le descripteur de l’assistant
  préparé avant signature, afin de distinguer les configurations des paquets.

La reprise passe par Service Management et reste soumise à l’accord de macOS.
Elle ne réinitialise pas les autorisations des autres applications. Une ancienne
entrée système incohérente peut encore nécessiter une intervention macOS ; cette
version ne garantit pas sa réparation. Les méthodes et limites matérielles de
contrôle de charge restent celles de la version 0.2.0.
