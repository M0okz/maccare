# MacCare 0.2.35

Les boutons de MacCare reprennent la forme en pilule de la tuile Ventilateurs, avec un libellé centré. La couleur permet de repérer le mode sélectionné et les actions destructives.

Le pointeur prend la forme d’une main sur les commandes actives, y compris les cartes de l’accueil, les lignes du tableau des processus et les onglets des Réglages. Les commandes désactivées gardent la flèche.

Dans la fiche d’un processus, les boutons « Quitter » et « Forcer à quitter » s’affichent sans points de suspension. Chacun demande toujours une confirmation.
