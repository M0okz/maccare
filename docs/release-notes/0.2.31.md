# MacCare 0.2.31

- L’accueil réunit la santé du Mac, la batterie et les mesures système dans une grille. Le bouton **Analyser** se trouve dans la carte Santé du Mac. La fenêtre garde une taille minimale adaptée à l’écran pour laisser le tableau des processus lisible.
- Le tableau **Processus** affiche la mémoire, le CPU, la puissance estimée et le PID. Vous pouvez trier les colonnes et rechercher un processus par nom ou PID. Jusqu’à trois applications dépassant 40 % de CPU sont signalées.
- Le volet latéral s’ouvre au survol de ses icônes. **Accès rapide** regroupe les outils et une bulle en bas de l’accueil signale les autorisations manquantes.
- La carte Batterie conserve en grisé les derniers accessoires déconnectés. Sur les Mac compatibles, la carte Ventilateurs propose les modes temporaires **Frais** et **Max**, avec retour automatique sous le contrôle de macOS.
- Une alerte thermique peut prévenir lorsque macOS signale un état thermique sérieux ou critique.

Si MacCare propose d’actualiser l’assistant système, cette étape donne accès aux nouvelles commandes de ventilation sur le matériel pris en charge.
