# MacCare 0.2.26

## Mise à jour d’iStat Menus

Corrige le refus de la mise à jour officielle d’iStat Menus 7.50.2 vers 7.50.3.
MacCare reconnaît le build fourni par Bjango et ne propose plus la même mise à
jour une fois installée. Les contrôles de signature et de téléchargement restent actifs.

Le libellé du catalogue précise aussi que Homebrew sert à détecter les versions :
une application téléchargée chez son éditeur reste prise en charge sans Homebrew installé.
