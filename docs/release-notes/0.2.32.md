# MacCare 0.2.32

- Le petit écran qui cligne de l’œil est la nouvelle icône de MacCare. Dans le Dock, son fond améthyste passe au prune en apparence sombre. Vous le retrouverez aussi au premier lancement et dans **À propos de MacCare**.
- Dans la barre des menus, ce même écran remplace les étincelles. Cliquez dessus pour ouvrir le volet de suivi du Mac.
- Le bouton **Analyser** de l’accueil et les accents du volet reprennent le violet de la nouvelle icône.
