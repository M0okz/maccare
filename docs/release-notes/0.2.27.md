# MacCare 0.2.27

## Un nouvel onglet À propos

Retrouvez la version de MacCare, les nouveautés disponibles et le bouton de
téléchargement dans **À propos**, juste sous **Mes outils**.

Lorsqu’une mise à jour est disponible, un **contour orange** et un symbole de
téléchargement attirent votre attention sur cet onglet. Le bouton jaune de la
barre de titre disparaît.

La page regroupe aussi les liens vers le site du projet, la documentation et
le code source. Le menu **À propos de MacCare** ouvre directement cette page.

Le téléchargement et l’installation restent gérés par le panneau de mise à jour
habituel : vous choisissez quand installer la nouvelle version.
