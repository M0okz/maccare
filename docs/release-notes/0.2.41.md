# MacCare 0.2.41

- **Volet de navigation.** Les icônes restent fixes quand les libellés se déploient. Le volet s’ouvre après 250 ms de survol et se referme après 320 ms hors du volet. Un bref passage du pointeur ne déclenche plus l’ouverture. Le bouton en bas répond immédiatement.
- **Accueil.** Les valeurs d’espace libre, de débit réseau et de ventilation s’alignent sur le pourcentage de batterie. Dans Santé du Mac, le score est légèrement abaissé et le motif est centré entre le score et la durée d’activité.
- **Batterie.** La ligne « Plus énergivore » affiche le nom de l’application propriétaire. La puissance indiquée reste celle du processus en tête du relevé. Si son application est inconnue, la carte indique « App non identifiée ».
