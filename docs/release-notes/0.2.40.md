# MacCare 0.2.40

- Le tableau des processus affiche un score énergétique de 0 à 20. Seul le nombre apparaît dans la colonne Énergie. Survolez son titre pour voir comment la charge CPU et les réveils du processeur contribuent au score.
- WindowServer prend sa place dans le classement par mémoire. Les applications qui regroupent plusieurs processus, comme Timon, affichent le PID qui s’ouvre dans leur fiche. Le compteur de l’en-tête indique le nombre de lignes regroupées.
- Les lignes du tableau réservent une place au repère de charge CPU, même au repos. La jauge CPU est plus large. La fiche d’un processus s’ouvre en fondu, une fois ses informations prêtes.
- Sur l’accueil, la courbe Mémoire montre la dernière minute et ajuste son échelle aux variations de RAM. Sous la courbe, vous pouvez lire les quantités de RAM et de swap utilisées.
