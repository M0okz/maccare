# MacCare 0.2.0

La rubrique Batterie réunit maintenant les réglages, les cycles, les programmations
et l’historique dans quatre onglets, avec son fond vert restauré.

- Profils d’utilisation prédéfinis et personnalisés, avec explication des réglages
  incompatibles avec le Mac.
- Historique local des mesures, conservé jusqu’à trente jours.
- Programmations de la limite, d’une recharge ponctuelle ou d’un cycle lorsque
  MacCare est ouvert ; les anciennes occurrences manquées ne sont pas rejouées.
- Décharge volontaire et étalonnage annulable sur les configurations compatibles.
  L’étalonnage est une action explicite, jamais activée par défaut.
- Commandes App Intents pour Raccourcis, avec les mêmes validations que l’interface.
- Diagnostic de compatibilité en lecture seule et récupération de l’alimentation
  après annulation, fermeture ou interruption de MacCare.

## Disponibilité et précautions

Les limites sous 80 % et le mode Voile demandent un contrôle matériel compatible.
Sur le M1 testé avec macOS 27.0.1 et le firmware 20457.1.29, macOS refuse ce contrôle :
MacCare utilise alors la limite native, de 80 à 100 %, et désactive les profils
incompatibles. Cette version ne fournit donc pas ces fonctions avancées sur cette
configuration. La pause thermique personnalisée est également indisponible avec
la limite native ; les protections thermiques de macOS restent actives.

Les cycles consomment volontairement la batterie. Un étalonnage peut durer plusieurs
heures et descendre vers 10 % ; il ne répare pas une batterie usée. Aucun cycle réel
complet ni essai physique de toutes les générations M2 à M6 n’a été réalisé.

Les métadonnées des quatre actions Raccourcis sont embarquées. Leur découverte
par macOS reste à vérifier sur la version distribuée ; plusieurs copies de MacCare
peuvent partager le même identifiant.

L’assistant système reste facultatif. Utilisez un seul contrôleur de charge à la fois.
macOS peut exceptionnellement dépasser sa limite pour son propre étalonnage.
