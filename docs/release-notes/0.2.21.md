# MacCare 0.2.21

**Version remplacée par la 0.2.22.** La vérification du DMG public a révélé
une erreur d’argument de `codesign` dans le parcours App Store : cette action
échoue avant l’installation. La signature du composant reste valide.
La correction est livrée dans la 0.2.22 ; les autres mécanismes restent inchangés.


## Mettez à jour vos applications depuis MacCare

Dans **Applications → Mises à jour**, le bouton **Mettre à jour** lance désormais
le téléchargement et l’installation des mises à jour compatibles. Une progression,
un résultat ou une explication d’échec remplace le simple lien vers le téléchargement.

MacCare utilise le mécanisme adapté : Sparkle de l’application, Homebrew pour
la copie réellement gérée par ce dernier, l’App Store ou une archive DMG/ZIP
fournie par le catalogue ou le dépôt officiel. Homebrew n’est pas nécessaire
pour installer une archive compatible. Les paquets PKG s’ouvrent dans
l’installateur macOS, puis leur installation peut être vérifiée dans MacCare.
L’App Store peut demander une autorisation administrateur macOS et votre session
App Store doit être connectée.

## Vous gardez le contrôle

Une application ouverte ne quitte qu’après votre confirmation. MacCare demande
une fermeture normale et ne force pas l’arrêt. Le téléchargement peut être
annulé avant l’installation. Une seule installation est engagée à la fois ;
l’analyse seule ne met aucune application à jour.

Pour un remplacement direct, MacCare contrôle le téléchargement, l’empreinte
SHA-256 lorsqu’elle est fournie, l’identifiant, la version, la signature et
l’éditeur, ainsi que la compatibilité. Gatekeeper doit accepter le nouveau paquet.
Les données et préférences hors du paquet sont conservées. MacCare lui-même
continue d’utiliser son propre mécanisme de mise à jour.

## Vérifications et limites

Le passage **PhotoCraft 0.21.0 → 0.22.0** a été vérifié avec les vrais DMG officiels
sur une copie isolée : téléchargement, contrôles, remplacement et conservation
d’un fichier de préférences de test. Un téléchargement altéré a été refusé sans
modifier l’ancienne copie. Le même parcours a été testé avec une copie signée
de MacCare 0.2.19 → 0.2.20.

Les parcours Homebrew, App Store, Sparkle tiers et PKG n’ont pas été validés en
installant des mises à jour sur les applications personnelles du Mac de test.
Certaines applications, signatures ou installations spécialisées peuvent demander
le mécanisme de leur éditeur. Pas de campagne VoiceOver complète ni de nouvelle
validation matérielle de la batterie dans cette livraison.
