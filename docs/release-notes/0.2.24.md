# MacCare 0.2.24

## Mise à jour d’iStat Menus

Corrige le refus « L’archive contient des chemins non autorisés » lors de la
mise à jour d’iStat Menus. Les grandes archives ZIP sont désormais vérifiées
à partir de leur liste complète de fichiers. Les protections contre les
chemins dangereux restent actives.

MacCare reconnaît aussi le build officiel d’iStat Menus 7.50.2, qui affiche
encore 7.50 dans ses métadonnées, pour éviter de proposer à nouveau cette
mise à jour après installation.

Le remplacement 7.50 (build 2355) vers 7.50.2 (build 2394) a été vérifié avec
les archives officielles sur une copie de test isolée, sans lancer iStat ni
modifier les applications personnelles.

Pour une application de l’App Store comme Bitwarden, macOS peut demander
l’autorisation d’un administrateur. Il s’agit du mot de passe de la session
Mac, pas du mot de passe du coffre Bitwarden. Cette demande n’est pas une
erreur de mise à jour. Aucune installation App Store sur une app personnelle
n’est revendiquée pendant cette validation.
