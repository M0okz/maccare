# MacCare 0.2.33

Sur l’accueil, le titre et les cartes s’adaptent désormais à la largeur de la fenêtre, même sur un grand écran. Quand vous réduisez la fenêtre, les cartes prennent moins de hauteur et laissent apparaître davantage de processus. La densité s’ajuste automatiquement pendant le redimensionnement.
