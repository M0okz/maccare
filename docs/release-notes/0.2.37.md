# MacCare 0.2.37

- **Espace disque.** La vue Évolution montre quels sous-dossiers ont grossi ou diminué depuis la dernière analyse. La référence est conservée après la fermeture de MacCare. Un clic ouvre le dossier dans la carte. Les mesures partielles sont signalées.
- **Smart Scan.** Lorsqu’une application ouverte est associée à un cache sélectionné, MacCare le garde en attente et poursuit le nettoyage. Le bilan indique quelle application quitter et propose de réessayer les éléments concernés.
- **Désinstallation.** MacCare explique la sélection de chaque élément, laisse les profils personnels décochés et protège les données qu’une autre application ou une autre copie identifiée utilise encore.
