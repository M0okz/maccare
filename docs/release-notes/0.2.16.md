# MacCare 0.2.16

## Une activité plus stable, un historique continu

Les chiffres CPU, GPU, mémoire et réseau sont lissés sur cinq secondes et les
cartes les actualisent toutes les trois secondes. Les courbes couvrent dix
minutes dans les cartes ; les détails proposent dix minutes, trente minutes ou
une heure, avec moyenne et pic. Le GPU possède désormais son propre détail.

Changer d’onglet ou fermer le volet ne recommence plus les courbes : un relevé
léger toutes les cinq secondes garde leur continuité tant que MacCare reste
ouvert. Les lectures de températures et de ventilateurs restent réservées aux
vues visibles. L’historique est borné en mémoire, sans fichier de cache.
L’échelle réseau varie par paliers pour éviter les changements incessants.

La veille suspend les relevés ; le tracé relie les points disponibles au réveil,
sans inventer de mesure ni de volume réseau pendant cette période. Quitter
complètement MacCare libère cet historique.

## Un gestionnaire Applications qui répond au clic

Les espaces vides des lignes deviennent cliquables dans les listes
d’applications, de données et de mises à jour. Les lignes de fichiers permettent
de cocher ou décocher leur contenu, en plus de la case elle-même.

La désinstallation d’un paquet dans `/Applications` ne rencontre plus le refus
« hors du périmètre de nettoyage ». Le paquet et toutes ses données associées
détectées sont cochés par défaut ; décochez les éléments à conserver. Le mode
corbeille et le mode de suppression directe utilisent le même traitement.
Les paquets retirés disparaissent du catalogue.

Une application en cours n’est pas fermée automatiquement avant le retrait de
ses fichiers.

## Vérifications et limites

La Dev a été vérifiée dans l’interface native : continuité des courbes après
navigation et réouverture du volet, sélecteurs d’historique, clics dans les
espaces vides et deux désinstallations d’applications factices avec leurs
préférences. Les 541 tests Swift réussissent, avec des cas de suppression
directe, de données seules, d’identité remplacée et de paquet voisin.

Ces vérifications ne constituent pas une campagne physique de veille, une
collecte native complète d’une heure, une campagne VoiceOver complète ou une
mesure énergétique prolongée. La distribution reste signée Developer ID et
notariée par Apple.
